# Snake Game - Multi-language Implementations

This repository contains the classic Snake game implemented in three different languages:

- **C** (using SDL2 for graphics and input)
- **Python** (using Tkinter for GUI)
- **JavaScript** (using HTML Canvas for browser-based gameplay)

Each implementation demonstrates core game logic, collision detection, and simple graphics/input handling. This is a fun project to explore how the same game can be built in multiple programming environments.
